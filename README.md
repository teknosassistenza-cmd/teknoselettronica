# TEKNOS – Sito React + Vite + Tailwind

## Comandi
```bash
npm install
npm run dev    # anteprima locale
npm run build  # build produzione
```

## Pubblicazione su Vercel
1. Crea account su https://vercel.com
2. Add New → Project → Upload
3. Seleziona la cartella del progetto
4. Deploy
5. Collega il dominio da Settings → Domains
